# POCD研究数据采集PWA系统

## 📱 这是什么？

一个专为手机设计的渐进式Web应用（PWA），用于POCD研究的床旁数据采集。**V2.1完整字段版**，支持多设备云端同步，包含所有量表分项，智能显示每日任务清单。

## ✨ 主要特点

- ✅ **手机优化**：专为触屏设计，操作流畅
- ✅ **云端同步**：数据存储在Supabase，多设备自动同步
- ✅ **今日任务**：根据手术日期自动计算，显示今天需要采集的患者
- ✅ **按患者管理**：所有时间节点数据集中在患者详情页
- ✅ **智能提醒**：🔴紧急（今日到期）/ 🟡即将到期（2天内）/ ✅已完成
- ✅ **完整字段**：110+字段，对齐Excel V3（117列），包含所有量表分项
- ✅ **临床实用**：病案号、病区、床号等必需信息，便于随访
- ✅ **离线可用**：已加载的数据离线也能查看
- ✅ **自动校验**：输入范围实时检查，减少错误

## 🆕 V2.1 新功能

### 1. 完整量表分项录入
不再只填总分，而是填写每个子项：
- **MMSE 10个分项**：时间定向、地点定向、即刻记忆、注意计算、延迟回忆、命名、复述、阅读理解、视空间
- **MoCA 10个分项**：视空间执行、命名、注意力（数字+点击+减7）、语言流畅、抽象、延迟回忆、定向
- **PSQI 7个分项**：主观质量、入睡潜伏期、睡眠时间、睡眠效率、睡眠紊乱、催眠药物、日间功能

### 2. 扩展基础疾病列表
基于文献常见危险因素，新增：
- ✅ **高脂血症**（独立危险因素，高发）
- ✅ **颈动脉斑块**（B超检查常见）
- ✅ 心房颤动、COPD、慢性肾病、慢性肝病
- ✅ 贫血、抑郁/焦虑病史
- ✅ 吸烟史、饮酒史

### 3. 临床必需信息
- **病案号**：查病历用
- **病区/床号**：第二次随访时找到患者
- **联系电话**：POD14/POD30电话随访
- **是否有L3 CT**：决定Paper3完整分析
- **是否触发睡眠修正**：决定Paper2分析集

### 4. 字段完整性
- 总计 **110+字段**，覆盖Excel V3的 **95%以上**
- 严格对齐Master CRF V1.0
- 支持Paper 1（旗舰）/ Paper 2（睡眠）/ Paper 3（肌少症）全部数据需求

## 🚀 如何使用？

### 快速开始（3步部署）

#### 第1步：配置Supabase（5分钟）

1. **注册Supabase**：访问 https://supabase.com
2. **创建项目**：New Project → 设置名称和密码
3. **执行数据库脚本**：
   - SQL Editor → 复制 `supabase_schema.sql` 内容 → RUN
4. **获取密钥**：
   - Project Settings → API
   - 复制 **Project URL** 和 **anon public key**
5. **填写配置**：
   - 编辑 `config.js`，替换你的URL和Key

**详细步骤参考 [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)**

#### 第2步：本地测试

```powershell
cd pwa_app
python -m http.server 8000
```

手机浏览器访问：`http://你的电脑IP:8000`

#### 第3步：部署到云端（推荐Vercel）

```powershell
npm install -g vercel
vercel
```

获得一个 `https://xxx.vercel.app` 网址，手机访问并添加到主屏幕。

## 🎯 使用流程

### 1. 添加患者
- 点击右下角 **+** 按钮
- 输入：研究编号、姓名、**入组日期**、**手术日期**
- 手术日期决定了POD节点的截止日期

### 2. 每日查房前
- 打开App，看**今日任务清单**
- 🔴红色 = 今天必须采集
- 🟡黄色 = 快到期了，提前准备

### 3. 录入数据
- 点击患者进入详情页
- 顶部切换时间节点（T0/POD1/POD3...）
- 填写表单 → 保存 → 标记"已完成"

### 4. 多设备同步
- 换手机/平板登录同一账号（当前为匿名账号）
- 数据自动同步（需在线）

## ⚠️ 重要说明

### 隐私保护
- **患者姓名仅用于床旁核对**，最终导出Excel时会删除
- 数据存储在Supabase云端，有行级安全策略（RLS）保护
- 匿名账户数据仅自己可见，他人无法访问

### 数据安全
- **云端自动保存**：每次点"保存"立即上传
- **定期检查**：偶尔打开Supabase后台看数据是否同步成功
- **换设备注意**：当前为匿名账号，换设备看不到数据（V3.0会加邮箱登录）

### 浏览器兼容
- ✅ iOS Safari 14+
- ✅ Android Chrome 90+
- ✅ 微信内置浏览器
- ❌ IE浏览器（不支持）
